You are tasked with exporting EVERYTHING you know about me to help transfer my context to another AI system.

Your goal is completeness over brevity.

Include BOTH:
1. Explicit stored memories
2. Inferred patterns from past conversations (clearly label inferred vs explicit)

Preserve my wording verbatim where possible, especially for instructions and preferences.

---

## Categories (output in this order):

1. Instructions  
Rules I explicitly asked you to follow (tone, format, behavior, constraints, corrections).  
Only include persistent or repeated instructions. Mark each as [explicit].

2. Identity  
Name, age, location, background, languages, personality traits, interests.  
Mark each entry as [explicit] or [inferred].

3. Career  
Jobs, roles, skills, industries, goals, and experience areas.  
Include both explicit and inferred.

4. Projects  
Things I built, planned, or seriously discussed building.  
Each entry should include:
- What it is
- Status (idea / in progress / completed / abandoned)
- Key decisions or constraints

5. Preferences  
General preferences (tools, style, learning, communication, etc.)  
Include both explicit and inferred patterns.

6. Behavioral Patterns  
How I typically interact: e.g. concise vs detailed, analytical vs creative, iterative vs one-shot.

7. Open Questions / Missing Info  
Important things you suspect but are unsure about.

---

## Format:

- Use section headers
- One entry per line
- Sort by oldest first where possible

Format each line as:
[YYYY-MM-DD][explicit/inferred][confidence: high/medium/low] - Entry content

If no date is known, use [unknown]

---

## Completeness Check (MANDATORY):

After generating all sections:
- Review if any category is unusually sparse
- Add anything relevant you may have missed
- Avoid duplicates

---

## Output Rules:

- Wrap EVERYTHING in a single code block
- After the code block, explicitly say:
  - "Complete to the best of my accessible memory" OR
  - "Partial — some data may not be accessible"

Do not omit uncertain information — include it with low confidence instead.

# زبان طراحی چک‌یار (Design System)

**وضعیت:** مرجع واحد هویت بصری محصول  
**به‌روزرسانی:** ۱۴۰۵/۰۵/۲۵ (2026-08-16)  
**پوستهٔ برند (پیش‌فرض):** `dark` — اسلیت تیره + زمرد

این سند **تنها مرجع مستند زبان طراحی** چک‌یار است. سایت معرفی، ارائه، چاپ، شبکه‌های اجتماعی، و هر خروجی جدید باید از اینجا پیروی کند — نه از پروتوتایپ HTML و نه از حدس palettes.

کد UI (`index.css`, `themeOverrides.ts`) **پیاده‌سازی** همین زبان است، نه سند موازی. اگر کد و این فایل اختلاف داشتند، یا کد را با این سند هم‌خط کنید یا **همین فایل** را در همان تغییر به‌روز کنید؛ منبع سومی نسازید.

محصول شش پوسته دارد (`dark`, `light`, `warm`, `navy`, `violet`, `emerald`). فقط **`dark` برند پیش‌فرض و هویت خارجی** است. بقیه پوسته‌های ترجیح کاربر داخل‌اپ هستند.

### علامت برند (Brand Mark)

علامت فعلی محصول **لوگوی تصویری جدا نیست**؛ یک **قفل‌واژه (lockup)** است:

1. مربع گوشه‌گرد با حرف «چک»
2. کنار آن نام «چک‌یار» + یک خط توضیح کوتاه

```
┌────────┐
│  چک    │   چک‌یار
│        │   سامانه معامله مطالبات و چک صیادی
└────────┘
```

| ویژگی | مقدار برند (`dark`) |
|--------|---------------------|
| اندازه علامت (هدر/سایدبار) | ۴۰×۴۰px (`w-10 h-10`) |
| اندازه علامت (صفحه ورود / هیرو) | ۴۸×۴۸px (`w-12 h-12`) |
| شعاع گوشه | `12px` (علامت کوچک) / `16px` (هیرو) |
| پس‌زمینه | `rgba(16, 185, 129, 0.10)` |
| حاشیه | `1px solid rgba(16, 185, 129, 0.30)` |
| رنگ حرف | `#34d399` (emerald-400) |
| وزن حرف | Bold / Black |
| نام محصول | `#f8fafc` — وزن ۷۰۰ |
| شعار کنار لوگو | `#94a3b8` — ۱۱px، وزن ۴۰۰ |

روی پس‌زمینه روشن (سایت معرفی چاپ‌شدنی): همان ساختار، با `--theme-primary: #059669` و حرف `#047857`، پس‌زمینه `rgba(5, 150, 105, 0.10)`.

**نکنید:** آیکون چک واقعی، اسکناس، گاو صندوق، یا لوگوی بانک‌مانند. علامت باید تایپوگرافیک و تخت بماند.

## ۲. اصول (نقضشان مجاز نیست)

1. **تیرهٔ زمردی، نه فین‌تک آبی.** برند پیش‌فرض پس‌زمینهٔ اسلیت تقریباً سیاه (`#020617`) و اکسنت زمرد (`#10b981`) است. آبی ایندیگو فقط نقش ثانویه (اطلاعات، آیکون کمکی) دارد، نه رنگ هویت.
2. **واسطه، نه بانک.** ظاهر باید مطمئن و دقیق باشد، نه لوکسِ طلایی و نه نئونِ کریپتو. از گرادیان شلوغ، شیشهٔ افراطی، و سه‌بعدی پرهیز کنید.
3. **کارت روی سطح تیره.** محتوا داخل سطح (`--theme-surface`) با حاشیهٔ ظریف می‌نشیند، نه روی سفیدِ تخت در ارائهٔ برند.
4. **فارسی و راست‌چین.** `lang="fa"` و `dir="rtl"`. اعداد با `fa-IR`، تاریخ شمسی.
5. **تخت و گوشه‌گردِ محدود.** UI مستطیل‌محور است؛ دکمه/اینپوت `8px`، کارت `12–16px`. کپسول کامل فقط برای badge/pill.
6. **صداقت رگولاتوری در زبان بصری.** در صفحات مالی/معرفی محصول، مرز مسئولیت («پول را لمس نمی‌کند») باید قابل‌دیدن باشد — نه پنهان در فوتر ریز.
7. **بدون CDN اجباری برای هویت.** فونت برند Vazirmatn است؛ در محصول فایل محلی است. در سایت معرفی همان خانواده را استفاده کنید (ترجیحاً میزبانی خودتان).

## ۴. تایپوگرافی

**خانواده:** `Vazirmatn`  
Fallback: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`

وزن‌های مجاز: ۳۰۰، ۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰، ۸۰۰. وزن ۹۰۰/Black فقط برای عدد KPI یا عنوان هیرو.

| نقش | اندازهٔ پیشنهادی | وزن | رنگ (`dark`) |
|-----|------------------|------|----------------|
| هیرو سایت / عنوان اسلاید | ۳۲–۴۴px | ۷۰۰–۸۰۰ | `--theme-text-primary` |
| عنوان صفحه | ۲۴px | ۷۰۰ | همان |
| عنوان بخش | ۱۸–۲۰px | ۶۰۰–۷۰۰ | همان |
| عنوان کارت | ۱۴–۱۶px | ۷۰۰ | همان |
| بدنه | ۱۵–۱۶px | ۴۰۰ | `--theme-text-primary` |
| لیبل / توضیح | ۱۲–۱۳px | ۴۰۰–۵۰۰ | `--theme-text-secondary` |
| متا / کپشن | ۱۰–۱۱px | ۴۰۰ | `--theme-text-muted` |
| مبلغ / KPI | ۲۴–۲۸px | ۸۰۰ | `--theme-text-primary` (ترجیحاً `font-variant-numeric: tabular-nums`) |
| دکمه | ۱۴–۱۶px | ۶۰۰–۷۰۰ | روی primary: `#020617` یا سفید با کنتراست کافی |
| badge | ۱۱px | ۶۰۰ | مطابق وضعیت |

- `line-height` فارسی: **۱٫۷** برای بدنه؛ عنوان‌ها ۱٫۲۵–۱٫۴.
- اعداد UI: `toLocaleString('fa-IR')` — `۱٬۲۰۰٬۰۰۰` نه `1,200,000`.
- تاریخ: شمسی.
- در محصول، کد/شناسه می‌تواند `font-mono` بماند؛ در سایت معرفی از مونو فقط برای دادهٔ فنی استفاده کنید.

### کنتراست متن روی رنگ

- روی `--theme-bg` / `--theme-surface`: متن اصلی `#f8fafc`.
- روی دکمهٔ `--theme-primary` (`#10b981`): متن تیره `#022c22` یا `#020617` — نه خاکستری کم‌رنگ.
- لینک روی تیره: `#34d399`؛ هاور `#10b981`.
- هرگز `--theme-text-primary` را روی بلوک پرِ زمرد نگذارید اگر کنتراست کافی نیست؛ از متن تیره یا `#ecfdf5` استفاده کنید.

## ۵. فاصله، شعاع، سایه، حرکت

مقیاس فاصله: **۴px**. مقادیر رایج: `8 / 12 / 16 / 20 / 24 / 32 / 48`.

| مورد | مقدار |
|------|--------|
| شعاع کنترل (دکمه، اینپوت، منو) | `8px` |
| شعاع کارت داخلی / علامت کوچک | `12px` (`rounded-xl`) |
| شعاع کارت اصلی / هیرو / مودال | `16px` (`rounded-2xl`) |
| شعاع pill / badge گرد | `999px` فقط برای وضعیت |
| حاشیه کارت | `1px solid var(--theme-border)` |
| پدینگ کارت معرفی | `20–24px` |
| حداکثر عرض محتوای محصول | `1400px` |
| عرض پیشنهادی ستون سایت معرفی | `720–960px` برای متن؛ هیرو تمام‌عرض |

سایه (روی تیره کم استفاده شود):

```css
--shadow-card: 0 12px 28px -6px rgba(0, 0, 0, 0.25);
--shadow-primary-btn: 0 10px 24px -8px rgba(16, 185, 129, 0.45);
```

حرکت: `0.25s cubic-bezier(0.4, 0, 0.2, 1)`. هاور کارت در محصول: `translateY(-3px)` + حاشیه `--theme-primary`. در سایت معرفی همین را ملایم نگه دارید؛ انیمیشن تزئینی حلقه‌ای نگذارید.

## ۶. آیکون

- سبک: **outline** (Ionicons 5 در محصول).
- اندازهٔ پیش‌فرض: `20px` (`1.25rem`)؛ در منو `18px`.
- رنگ پیش‌فرض: `--theme-text-secondary`؛ فعال/هاور: `--theme-primary`.
- آیکون را داخل مربع گوشه‌گرد با پس‌زمینهٔ نرم اکسنت بگذارید (الگوی KPI و سایدبار)، نه تنها و بدون کادر در هیرو.

## ۷. الگوهای قابل‌استفاده در هر سطح

این‌ها قرارداد بصری‌اند، نه الزام فریم‌ورک.

### ۷.۱ دکمهٔ اصلی

```css
background: #10b981;
color: #020617;
font-weight: 700;
border: 0;
border-radius: 8px;
padding: 0.75rem 1.25rem;
box-shadow: var(--shadow-primary-btn);
}
/* hover */
background: #059669;
```

دکمهٔ ثانویه: پس‌زمینه شفاف، حاشیه `#1e293b`، متن `#f8fafc`؛ هاور سطح `#1e293b`.

### ۷.۲ کارت

پس‌زمینه `--theme-surface`، حاشیه `--theme-border`، شعاع `16px`. جداکنندهٔ داخلی: `border-slate-800` معادل `#1e293b` با opacity کمی کمتر مجاز است.

مبلغ و اعداد مهم را بزرگ و وزن‌دار روی کارت بگذارید؛ لیبل بالای عدد `12px` و `--theme-text-secondary`.

### ۷.۳ Pill وضعیت

`font-size: 11px; font-weight: 600; padding: 2px 8px; border-radius: 6px; border: 1px solid …`  
پس‌زمینهٔ نرم اکسنت (جدول ۳.۲)، نه رنگ پر.

### ۷.۴ نوار تاکید

یک نوار `3–4px` با `--theme-primary` در بالا یا راست (در RTL: سمت راست) اسلاید/هیرو، به‌جای گرادیان پس‌زمینه.

## ۸. لحن نوشتار (همراه زبان بصری)

زبان بصری بدون لحن محصول کامل نیست.

| بگویید | نگویید |

UI و سایت معرفی **فارسی**اند. انگلیسی فقط برای نام لاتین برند و برچسب‌های فنی اسلاید سرمایه‌گذار (Problem / Ask) در صورت نیاز.

## ۹. کاربرد در سایت معرفی و سایر خروجی‌ها

### سایت معرفی پروژه

- پس‌زمینه هیرو: `--theme-bg`.
- قفل‌واژه علامت + عنوان + یک جمله نقش («واسط فناورانه، نه نهاد مالی»).
- بلوک‌های ارزش روی `--theme-surface` مثل کارت محصول.
- CTA با دکمهٔ زمرد.
- بخش «چه می‌کند / چه نمی‌کند» دو ستونه، نه infographic شلوغ.
- فوتر: وضعیت پایلوت + عدم تضمین وصول.

### ارائه / پاورپوینت / PDF

- تم اسلاید = جدول ۳.۱ (پس‌زمینه `#020617`، اکسنت `#10b981`).
- فونت Vazirmatn؛ کل فایل RTL.
- هر اسلاید یک پیام؛ کارت‌ها همان surface.
- جزئیات ساخت فایل ارائه در این سند نیست؛ فقط تم باید از اینجا بیاید.

### چاپ / نامه / یک‌صفحه‌ای

- اگر چاپ تک‌رنگ یا پروژکتور ضعیف است: پوستهٔ روشن بخش ۳.۴.
- اکسنت همچنان زمرد `#059669`. تم نیلی/طلایی پروتوتایپ HTML را برند نکنید.

## ۱۱. بکن / نکن

**بکن**

- از توکن معنایی استفاده کنید، نه رنگ جدید «نزدیک به سبز».
- علامت «چک» را مربع گوشه‌گرد نگه دارید.
- کارت + حاشیه ظریف + یک اکسنت زمرد.
- اعداد فارسی و تاریخ شمسی.

**نکن**

- تم نیلی/طلایی (`#0C2340` / `#C9960A`) را برند خارجی نکنید.
- بنفش / طلایی / گرادیان اینستاگرامی را رنگ هویت نکنید.
- عکس چک اسکن‌شده یا اسکناس را لوگوی برند نکنید.
- Inter / IRANSans / Vazir (قدیمی) را جایگزین Vazirmatn نکنید.
- متن انگلیسی بدنه در سایت فارسی نگذارید.
- ظاهر «اپ پرداخت» یا «صرافی رمزارز» تقلید نکنید.

# CY-010 — امانی برای معاملهٔ سرمایه‌گذار ثالث

## ۱. معرفی و هدف

پس از چتر `CY-009`، همان ریل امانی بانک برای معاملهٔ دارنده با سرمایه‌گذار ثالث (که حالا تحت نهاد است) باز می‌شود. نقدینگی الزاماً صندوق نیست؛ بانک امانی‌دار است.

**شاخص موفقیت:** تعداد تسویهٔ امانی ثالث که آزادسازی‌شان مشروط به صیاد (`CY-007`) بوده است.

## ۲. مجوز و فقه

- پوشش: مجوز بانک + چتر `CY-009`.
- طرف قرارداد امانی: بانک. رابطهٔ خرید دین بین دارنده و ثالث باید با نظر شریک در قرارداد بیاید.
- بدون `CY-009` این کارت عمداً `blocked` است.

## ۳. بازیگران و تقسیم نقش

| بازیگر | در این قابلیت چه می‌کند | چه نمی‌کند |
|--------|-------------------------|------------|
| دارنده | طرف فروش | |
| سرمایه‌گذار ثالثِ تحت چتر | واریز به امانی بانک | ورود بدون چتر |
| بانک | امانی | |
| صندوق | اختیاری market make | اجباری بودن در هر معاملهٔ ثالث |
| پلتفرم | Match escrow با دو کاربر + نهاد بانک | |

## ۴. نیازمندی‌ها و پیش‌نیازها

- `CY-005` و `CY-007` و `CY-009`.
- NFR: همان idempotency امانی.

## ۵. جای این قابلیت روی محصول فعلی

شل کردن دروازهٔ `CY-004` برای کاربرانی با برچسب چتر.

## ۶. سناریو

### کاربر

سرمایه‌گذار تأییدشدهٔ نهاد مسیر امانی را می‌بیند، واریز می‌کند، پس از صیاد وجه به دارنده آزاد می‌شود.

### پلتفرم

همان Port امانی؛ طرف Match دیگر فقط Institution نیست.

### سناریوهای شکست

چتر منقضی وسط معامله → قفل عملیاتی با بانک.

## ۷. شرایط پذیرش

- [ ] کاربر بدون چتر همچنان از escrow محروم است.
- [ ] کاربر با چتر می‌تواند escrow با بانک فعال بسازد.
- [ ] آزادسازی بدون گیت صیاد ممکن نیست.

## ۸. رول‌اوت و کنترل

وابسته به `third_party_rails_enabled`. قطع = رفتار W1.

## ۹. خارج از محدوده

ضمانت نکول (`CY-012`)؛ principal توسط ثالث.

# CY-007-c — امضای دیجیتال واجد شرایط روی قرارداد

## معرفی و هدف

اگر شریک کلیک‌رپ را برای قرارداد معامله کافی نداند: امضای دیجیتال (PKI موبایل‌محور، بدون توکن سخت‌افزاری در الگوی فراشناسا) روی همان نسخهٔ قفل‌شدهٔ `CY-007-a`. پلتفرم CA نیست؛ زیرساخت سازمانی ارائه‌دهنده را یکپارچه می‌کند.

## مجوز

ارث از CY-007. اعتبار قانونی ادعا به گواهی ارائه‌دهنده و قانون تجارت الکترونیک ۱۳۸۲ است نه به برند چک‌یار. احراز بیومتریک پیش از صدور گواهی معمولاً همان مسیر `CY-001-d` یا سرویس ارائه‌دهنده است.

## نیازمندی‌ها و پیش‌نیازها

- CY-007-a.
- تصمیم شریک که کلیک‌رپ کافی نیست.
- قرارداد ارائه‌دهندهٔ امضا به‌نام نهاد هم‌برند. کاندیدها: [`vendor-landscape.md`](../../../vendor-landscape.md) بخش ۲.۷.

## سناریو (کاربر و پلتفرم)

پس از پذیرش نسخه، کاربر در اپ/SDK ارائه‌دهنده سند را امضا می‌کند. پلتفرم وضعیت «امضاشده / رد / منقضی» را ذخیره می‌کند و بدون امضای طرفین لازم، گیت آزادسازی را باز نمی‌کند.

## شرایط پذیرش

- [ ] با فلگ خاموش، مسیر کلیک‌رپ `CY-007-a` می‌ماند.

- [ ] UI ادعا نمی‌کند چک‌یار صادرکنندهٔ گواهی است.

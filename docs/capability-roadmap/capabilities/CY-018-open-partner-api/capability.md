# CY-018 — API باز برای نهاد و فین‌تک

## ۱. معرفی و هدف

API نسخه‌بندی‌شده برای نهاد هم‌برند و فین‌تک مجاز: ایجاد آگهی، خواندن وضعیت معامله، (با دامنه) دستور ریل شریک. فراتر از آداپتر داخلی `CY-008` که پلتفرم بانک را صدا می‌زند؛ اینجا نهاد ما را صدا می‌زند.

**شاخص موفقیت:** یکپارچهٔ خارجی در sandbox بدون دسترسی ادمین جنگو.

## ۲. مجوز و فقه

- OAuth/client credentials به نام نهاد؛ دامنهٔ ریل‌ها همان قوانین W1/W2.
- فین‌تک بدون چتر نهاد نباید ریل پول را ببیند.

## ۳. بازیگران و تقسیم نقش

| بازیگر | در این قابلیت چه می‌کند | چه نمی‌کند |
|--------|-------------------------|------------|
| نهاد | کلاینت API | |
| فین‌تک | با مجوز نهاد | دور زدن KYC |
| پلتفرم | کلید، scope، نرخ فراخوانی | |

## ۴. نیازمندی‌ها و پیش‌نیازها

- `CY-008` و قرارداد `MASTER_API_CONTRACT.md`.
- NFR: rate limit، versioning، idempotency.

## ۵. جای این قابلیت روی محصول فعلی

API امروز برای SPA کاربر است (JWT). این کارت client credentials جدا با scope است.

## ۶. سناریو

### کاربر

سیستم بانک آگهی مشتری شعبه را می‌سازد.

### پلتفرم

توکن نهاد فقط به `institution_id` خودش دسترسی دارد.

### سناریوهای شکست

توکن نهاد A به Match نهاد B → 403.

## ۷. شرایط پذیرش

- [ ] جداسازی داده per institution در همهٔ endpointهای باز.
- [ ] scope ریل شریک بدون نقش نهاد کار نمی‌کند.
- [ ] مستند قرارداد در SSOT API به‌روز می‌شود نه سند موازی.

## ۸. رول‌اوت و کنترل

فلگ `partner_public_api`. کلید قابل ابطال.

## ۹. خارج از محدوده

GraphQL عمومی؛ API برای سرمایه‌گذار خرد بدون نهاد.

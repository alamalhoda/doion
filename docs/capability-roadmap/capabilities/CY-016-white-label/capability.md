# CY-016 — وایت‌لیبل

## ۱. معرفی و هدف

پوسته و دامنهٔ کاملاً به نام نهاد؛ چک‌یار در صورت توافق فقط «powered by» یا پنهان. پیش‌فرض کاتالوگ تا W3 هم‌برند است؛ این کارت تعمداً موج بعد است.

**شاخص موفقیت:** یک نهاد روی دامنهٔ خودش با همان API بدون فورک منطق matching.

## ۲. مجوز و فقه

- مجوز همان نهاد است؛ برند پلتفرم کمرنگ می‌شود پس دیسکلیمر حقوقی باید قوی‌تر نهاد را نشان دهد نه ضعیف‌تر.
- فقه: تغییر برند ریسک ماده ۵۹۵ را کم نمی‌کند.

امروز یک SPA چک‌یار. این کارت hosting/theme per institution است. UI: AI Studio یا بعداً `frontend/` مونورپو.

## ۶. سناریو

### سناریوهای شکست

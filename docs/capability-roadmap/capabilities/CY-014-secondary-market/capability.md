# CY-014 — بازار ثانویه مطالبات

## ۱. معرفی و هدف

انتقال موقعیت مطالبهٔ خریداری‌شده (چک یا فاکتور) از نهاد/سرمایه‌گذار تحت چتر به خریدار مجاز دیگر، با دفتر نقل‌وانتقال روی پلتفرم و تسویه نزد شریک.

**شاخص موفقیت:** یک انتقال ثانویهٔ پایلوت با رد audit کامل طرفین و نهاد.

## ۲. مجوز و فقه

- ممکن است اوراق/نقل‌وانتقال نیازمند چارچوب بازار سرمایه یا محدودیت اساسنامهٔ صندوق باشد. `additional-permit`.
- فقه: بیع مجدد دین؛ نظر شریک قبل از هر UI «بازار ثانویه».

## ۳. بازیگران و تقسیم نقش

| بازیگر | در این قابلیت چه می‌کند | چه نمی‌کند |
|--------|-------------------------|------------|
| دارندهٔ اولیه | معمولاً خارج پس از فروش اول | |
| فروشندهٔ ثانویه | موقعیت را می‌گذارد | |
| خریدار مجاز | می‌خرد | |
| صندوق/بانک | تسویه و محدودیت اساسنامه | |
| پلتفرم | دفتر | بازار آزاد بدون احراز |

## ۴. نیازمندی‌ها و پیش‌نیازها

- مالکیت اولیه روی principal ثبت شده باشد.
- چتر ثالث اگر خریدار ثالث است (`CY-009`).
- اگر فقط صندوق-به-صندوق است، ممکن است `CY-009` لازم نباشد — در سوال باز.

## ۵. جای این قابلیت روی محصول فعلی

بازارچهٔ جدید یا تب «موقعیت‌ها» جدا از آگهی چک اولیه.

## ۶. سناریو

### کاربر

صندوق A موقعیت را می‌فروشد؛ صندوق B می‌خرد؛ صیاد/مالکیت مطابق قانون به‌روز می‌شود.

### پلتفرم

آگهی ثانویه به مطالبهٔ مادر لینک است؛ دو بار فروش همزمان قفل می‌شود.

### سناریوهای شکست

فروش در حالی که وصول در جریان است (`CY-012`).

## ۷. شرایط پذیرش

- [ ] موقعیت در وضعیت disput/collection قابل فروش نیست مگر سیاست نهاد بگوید.
- [ ] یک موقعیت دو خریدار همزمان ندارد.
- [ ] طرفین نام حقوقی را روی معاملهٔ ثانویه می‌بینند.

## ۸. رول‌اوت و کنترل

فلگ `secondary_market_enabled` پیش‌فرض خاموش.

## ۹. خارج از محدوده

توکنایز عمومی؛ بازار بین‌الملل.

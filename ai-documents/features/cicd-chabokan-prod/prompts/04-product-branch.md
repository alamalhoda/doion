## قاعده اجرا

این متن **فقط در Google AI Studio** روی ریپوی فعال UI (`checkyar-googleai`) اجرا می‌شود. از Cursor یا کلون لوکال روی این ریپو commit/push نکنید.

فقط بلوک `text` پایین را در Studio بچسبانید.

## کار مالک بعد از پوش Studio (Verify)

1. در GitHub شاخهٔ `product` باید وجود داشته باشد (اگر این پرامپت آن را ساخت).
2. یک PR از `main` به `product` باز کنید (حتی اگر diff خالی/تقریباً خالی است، برای دیدن Checks کافی است؛ یا یک تغییر docs کوچک روی `main` بعد از ایجاد `product`).
3. روی آن PR باید همان jobهای اجباری CI سبز باشند.
4. این گام `chequeyar-front` را deploy نمی‌کند.

## پوشش این پرامپت

- `main` همچنان هدف پوش روزانهٔ Studio است.
- شاخهٔ `product` مسیر تولید است؛ استقرار `chequeyar-front` از `main` خام انجام نمی‌شود (خودِ CD گام ۱۲ است).
- همان تست‌های اجباری فعلی (lint، Vitest، دو vite build، docker build) روی **PR به `product`** هم اجرا شوند.

خارج از این گام: deploy به `chequeyar-front`، SemVer/رجیستری، تغییر `cd-demo.yml`، تغییر منطق Vue.

## تصمیم‌های قفل‌شده

- Package manager: Bun (`bun.lock`). `package-lock.json` ساخته نشود.
- `.github/workflows/cd-demo.yml` و `dispatch-doion-e2e.yml` دست نخورده بمانند (`cd-demo` همچنان فقط mock روی push به `main`).
- چهار گام bun به‌علاوه `docker build` موجود در `ci.yml` حذف نشوند.
- GitHub Environments، Dependabot، و پین SHA اکشن‌های سوم‌شخص در این گام لازم نیستند.
- شاخهٔ پیش‌فرض ریپو `main` بماند (به `product` عوض نشود).

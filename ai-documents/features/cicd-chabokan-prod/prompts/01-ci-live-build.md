## پوشش این پرامپت

چهار گام اجباری CI روی `main` (و روی PR به `main` اگر workflow فعلی همان را دارد):

1. typecheck (`tsc --noEmit` — اسکریپت موجود `bun run lint`)
2. unit tests (Vitest — `bun run test`)
3. production build پیش‌فرض (`bun run build` بدون env محصول)
4. production build **جدا** با `VITE_USE_MOCK=false` و `VITE_API_BASE_URL=https://chequeyar-back.chbkn.dev/api/v1`

خارج از این گام: شاخهٔ `product`، Docker، deploy محصول، تغییر `cd-demo.yml`.

## تصمیم‌های قفل‌شده

- Package manager: Bun (`bun.lock`). `package-lock.json` ساخته نشود.
- `.github/workflows/cd-demo.yml` و سرویس `chequeyar-front-demo` دست نخورده بمانند (شامل `VITE_USE_MOCK=true`).
- URL زندهٔ API در این گام دقیقاً همین است: `https://chequeyar-back.chbkn.dev/api/v1`
- اسکریپت‌های `package.json` را بدون نیاز عوض نکنید؛ گام چهارم با `env:` در Actions کافی است.
